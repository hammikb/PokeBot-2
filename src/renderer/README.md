# Renderer Layout

- `src/pages/` — one component per navigable screen.
- `src/components/` — reusable page sections and controls.
- `src/store/` — renderer state and typed IPC actions.
- `src/assets/` — global styles and static visual assets.

The catalog and product-task workflow is intentionally combined on the Tasks
screen. The `/catalog` route remains only as a compatibility redirect.
